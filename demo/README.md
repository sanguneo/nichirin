# demo — 소개용 목업

실제 대화로 스크린샷을 찍으면 남의 대화를 공개하게 됩니다. 이 폴더의 기존 화면은
`demo/mockup.py`가 **전부 지어낸 프로필**을 메모리에 만들어 촬영한 것입니다.
여기 있는 이름, 메시지, 방은 어느 것도 실존하지 않고, 실제 계정이나 데이터베이스를
촬영한 것이 아닙니다. macOS 실데이터 스크린샷으로 소개하지 마세요.

## 기존 화면과 포팅 상태

`shots/`에는 대화방 목록(`rooms`), 대화(`chat`), 다이제스트(`digest`), 친구(`friends`),
이름 이력(`real`), 목록 필터(`filter`), 전송 확인(`sent`), 새 메시지 표시(`unseen`),
에이전트 JSON(`cli`)의 합성 화면이 있습니다.

**데모 생성기는 아직 macOS 포팅 대상입니다.** `mockup.py`의 가짜 DB는 이전 클라이언트의
테이블·분할 DB 구조를 사용하므로 현재의 단일 `NTChatRoom` / `NTChatMessage` DB를 읽는
런타임과 맞지 않습니다. 명령의 `python`만 `python3`로 바꿔서는 재생성되지 않습니다.
기존 스크린샷은 목업 참고 자료로 남깁니다. 실제 계정으로 대신 실행해 촬영하지 마세요.

`capture.ps1`은 원본 Windows용 캡처 스크립트입니다. 보존된 도구일 뿐 macOS에서는
지원하지 않습니다. 데모 DB를 포팅한 뒤에는 합성 장면을 터미널에 띄우고
**Shift+Command+4 → Space**로 해당 창만 캡처할 수 있습니다. 주변의 실제 대화나
연락처가 화면에 섞이지 않았는지 확인하세요.
