# kamado 소개 문구

스크린샷은 전부 `demo/mockup.py`가 만든 **합성 데이터**입니다. 실제 대화·실제 사람은
한 줄도 들어 있지 않습니다. 기존 목업 화면이며 macOS 실데이터를 촬영한 것이 아닙니다.

---

## 한 줄

> **내 Mac에 이미 있는 카카오톡 대화를, 터미널에서 읽고 답합니다.**

대안 문구:

- 카카오톡을 꺼도 내 Mac에 저장된 대화는 읽을 수 있습니다.
- 서드파티 런타임 패키지 0개. macOS 카카오톡을 읽는 Python 3.9+ CLI + 터미널 UI.
- 읽기는 로컬에서, 보내기는 당신이 허락한 그 창으로만.

## 세 줄

> 카카오톡은 대화를 SQLCipher로 암호화해 내 Mac에 저장합니다. **kamado**는
> 기기와 계정 정보에서 열쇠를 유도해, 클라이언트가 닫혀 있어도 그 기록을 읽습니다.
> 보내기는 로그인된 클라이언트의 접근성 입력창으로만. 포커스·커서·클립보드는 그대로입니다.

## 스크린샷 캡션

| 파일 | 캡션 |
| --- | --- |
| `demo/shots/rooms.webp` | **로컬에 저장된 방을 읽습니다.** 한 DB에 모든 방이 들어 있고, 읽으려고 방마다 창을 열 필요는 없습니다. |
| `demo/shots/chat.webp` | **답장은 무엇에 답한 것인지, 멘션은 누구를 부른 것인지.** `@`는 나를 부른 줄, `↳`는 답한 줄. |
| `demo/shots/digest.webp` | **`/sum`은 요약하는 척하지 않습니다.** 모델 없이 활동량·화자·단어·대표 문장을 뽑습니다. |
| `demo/shots/friends.webp` | **친구 목록도 로컬에서.** 즐겨찾기와 상태 메시지까지, 전화번호는 명시적으로 요청할 때만. |
| `demo/shots/real.webp` | **이 방에 지수가 두 명입니다.** `/real 지수`는 이름이 아닌 `userId`로 관측된 이력을 구분합니다. |
| `demo/shots/filter.webp` | **`/`로 목록을 좁힙니다.** 방이 많아도 방향키만 누르고 있을 필요는 없습니다. |
| `demo/shots/sent.webp` | **확인한 만큼만 표시합니다.** `*`는 제출, `✓`는 로컬 기록에서 확인, `?`는 아직 확인하지 못한 전송입니다. |
| `demo/shots/unseen.webp` | **과거를 읽는 중이면 화면을 빼앗지 않습니다.** 새 메시지는 아래에 쌓이고 상태줄로 알립니다. |
| `demo/shots/cli.webp` | **에이전트가 받는 것.** 명령 하나에 방·메시지·`coverage`·`attention`이 함께 옵니다. |

## macOS에서 달라진 것

- **열쇠를 유도합니다.** `IOPlatformUUID`와 계정 `userId`로 PBKDF2-HMAC-SHA256을
  100,000회 적용합니다. 프로세스 메모리를 스캔하지 않고, 읽을 때는 클라이언트가 필요 없습니다.
- **DB는 하나입니다.** 모든 방·메시지·사용자가 앱 컨테이너의 단일 SQLCipher DB에 있습니다.
  macOS CommonCrypto를 `ctypes`로 호출하므로 별도 암호화 패키지가 필요 없습니다.
- **먼저 사본을 고정합니다.** APFS의 `cp -c`로 copy-on-write 복제를 만든 뒤 읽습니다.
  클라이언트가 쓰는 큰 DB를 그대로 끝까지 쫓아 읽지 않습니다.
- **권한은 터미널 앱에 줍니다.** 읽기에는 전체 디스크 접근 권한, 보내기에는 추가로
  손쉬운 사용 권한이 필요합니다. 권한 부족으로 접근이 멈추는 상황은 시간 제한과
  `PERMISSION_REQUIRED`로 설명합니다.
- **이름은 지금 이름일 뿐입니다.** 현재 `NTUser` 이름과 메시지가 쓰인 시점의 이름은
  다를 수 있습니다. 이름 이력은 멤버십 피드와 도구가 관측한 이름을 합친 것이며 완전하지 않습니다.
- **보내기는 지정한 창으로만.** Accessibility로 `AXValue`에 글자를 넣고 그 창의 전송
  버튼을 누릅니다. `AXValue`로 넣은 글자 위의 Return은 클라이언트가 무시하므로, 버튼이
  실제로 보내는 동작입니다. 초안은 지우되 `clearedDraft`로 알립니다. `submitted`는
  입력창이 비워졌다는 뜻이지 전달 확인이 아닙니다.

## 못 하는 것 (먼저 말합니다)

- macOS 전용입니다. Python 3.9 이상을 쓰며 macOS 15.7에서 확인했습니다.
- 로컬 캐시만 보입니다. 서버의 전체 이력이 아니며, 검색 결과가 없다고 대화가 없었던 것은 아닙니다.
- 사진·파일·이모티콘은 렌더하지 않습니다. 종류를 아는 것과 내용을 본 것은 다릅니다.
- 첨부 전송, 로그인 자동화, 프로토콜 재구현, 기록 수집은 범위 밖입니다.
- 실제 전송에는 실행 중이며 로그인된 카카오톡이 필요합니다. 전송 간격은 최소 2초,
  받는 방과 내용은 사용자 확인 후에, 실제 테스트는 나와의 채팅이나 허락받은 테스트 방에서만.

## AI 에이전트용 한 문단

> 설치하면 스킬이 됩니다. `context` 한 번이면 방을 특정하고, 최근 메시지를 오래된
> 순으로 주고, **얼마나 아는지**를 함께 말합니다. `coverage`는 로컬 범위와 최신 여부를,
> `attention`은 이 창에서 나를 부른 줄과 내 말에 달린 답장을 알려줍니다.
> 초안을 부탁한 것은 보내도 된다는 뜻이 아닙니다.
